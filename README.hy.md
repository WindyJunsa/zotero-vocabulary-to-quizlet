# Vocabulary to Quizlet — Բառապաշար՝ Quizlet-ի համար

[English](README.md) | **Հայերեն**

**Հեղինակ՝ Huziqian** · Zotero 10 · Հայերեն → անգլերեն

PDF-ում ընտրեք բառ կամ արտահայտություն և սեղմեք **＋ Ավելացնել բառապաշարին**։
Կոճակը հայտնվում է տեքստի ընտրության պատուհանում՝ LLM հավելման **Add Text** կոճակի տակ։
Բառը պահպանվում է Zotero-ի աջ կողային բառապաշարում։ Ընդգծում ստեղծելու կարիք չկա։

## Տեղադրում և լեզվի ընտրություն

Ներբեռնեք [v0.3.0 հավելումը](vocabulary-to-quizlet-0.3.0.xpi)։
Zotero-ում բացեք **Tools → Plugins → ⚙ → Install Plugin From File** և ընտրեք `.xpi` ֆայլը։
Հավելման նույնացուցիչը չի փոխվել․ թարմացումը պահպանում է ձեր բառացանկն ու իմաստները։

Բացեք աջ կողմի բառապաշարի գրքի պատկերակը։ **Interface language / Միջերեսի լեզու**
ցանկից ընտրեք **English**, **Հայերեն** կամ **Automatic / Ավտոմատ**։
Ավտոմատ ռեժիմը հայերեն է օգտագործում, եթե Zotero-ի լեզուն հայերեն է, իսկ այլ դեպքերում՝ անգլերեն։
Ընտրության նոր պատուհանները բացվում են ընտրված լեզվով։ Արդեն բաց պատուհանը փակեք և նորից ընտրեք բառը։
Գործիքների ցանկի լեզուն թարմացնելու համար վերագործարկեք Zotero-ն։
Կողային բաժնի վերնագիրը հետևում է Zotero-ի լեզվին։
Միջերեսի լեզուն չի փոխում թարգմանության ուղղությունը՝ հայերենից անգլերեն։

## Ինչպես օգտագործել

1. PDF-ում ընտրեք հայերեն բառը կամ արտահայտությունը։
2. Ցանկության դեպքում գրեք անգլերեն իմաստը և սեղմեք **Ավելացնել բառապաշարին**։
3. **Ավելացնելիս թարգմանել անգլերեն** տարբերակը միացնելու դեպքում դատարկ իմաստները
   լրացվում են [Translate for Zotero](https://github.com/windingwind/zotero-pdf-translate)
   հավելման միջոցով՝ ձեր ընտրած ծառայությամբ։ Ուղարկվում է միայն ընտրված տեքստը։
4. Կողային վահանակում խմբագրեք բառերն ու իմաստները, որոնեք, ցուցադրեք միայն ընթացիկ PDF-ի
   բառերը կամ բացեք սկզբնաղբյուրի էջը։ Հեռացված բառը կարելի է վերականգնել։
5. Սեղմեք **Պատճենել ամբողջ ցուցակը** կամ **Պատճենել և բացել Quizlet-ը**։
   Quizlet-ում ընտրեք **Create → Flashcard set → Import**։ Տեղադրեք ցուցակը,
   ընտրեք **Tab**՝ բառի և իմաստի միջև, **New line**՝ քարտերի միջև։ Ստուգեք և պահպանեք։

Ստուգեք մեքենայական թարգմանությունները, հատկապես հոլովված կամ խոնարհված ձևերը։
Առանց Translate for Zotero-ի կարող եք պահպանել բառերը և ձեռքով լրացնել իմաստները։
Ուշացած թարգմանությունը չի փոխարինում ձեր ձեռքով խմբագրած իմաստը։

## Տվյալներ և սահմանափակումներ

- Բառացանկը պահպանվում է այս համակարգչի Zotero-ի կարգավորումներում։ Այն չի համաժամացվում Zotero Sync-ով։
- Նույն բառի աղբյուրները միավորվում են։ Տարբեր իմաստները կարող եք գրել նույն դաշտում։
- Գրքերը, PDF-ի նշումները և առկա գրառումները չեն փոփոխվում։
- Հավելումը չի պահպանում API բանալիներ կամ Quizlet-ի մուտքի տվյալներ։
- Պատճենվում է ամբողջ գործող ցուցակը՝ անկախ որոնման կամ PDF-ի զտիչից։ Դատարկ իմաստները կանխում են արտահանումը։
- Quizlet API-ով անմիջական հրապարակում չկա։ Պետք է ինքնուրույն տեղադրել պատճենված ցուցակը։
- Tools-ի հին արտահանման պատուհանը պահպանում է իր սևագրերը և առանձին արտահանում է PDF-ի ընդգծումներն ու մեկնաբանությունները։
- Թարմացումները տեղադրվում են ձեռքով։

## Մշակում

Պահանջվում են Node.js և Python, առանց npm կախվածությունների։

```sh
node --test test.cjs vocabulary.test.cjs i18n.test.cjs
python build.py
```

Պատրաստ ֆայլերը գտնվում են `dist/` պանակում։ Արխիվում չեն ներառվում անձնական բառապաշարը,
մուտքի տվյալները կամ Zotero-ի տվյալները։ Թեստերը ստուգում են արտահանումը, պահպանումը,
թարգմանության ընթացքի փոփոխությունները և միջերեսի լեզուները։

Անկախ նախագիծ է․ կապված չէ Zotero-ի կամ Quizlet-ի հետ։ MIT արտոնագիր։
